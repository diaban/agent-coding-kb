# Scenarios

* [Scenarios](overview.md) - Six competing futures for code and languages, how they combine, and the current bet.
* [Scenario 1: lock-in](01-lock-in.md) - Dominant languages are hardened, not replaced, and niche languages decline.
* [Scenario 2: the specification becomes the language](02-spec-as-language.md) - Specifications and tests become what humans read; code is regenerated.
* [Scenario 3: all-harness](03-all-harness.md) - Most code becomes disposable under an agent harness; software splits into two layers.
* [Scenario 4: the backlash](04-backlash.md) - Incidents trigger audit requirements and human readability becomes mandatory again.
* [Scenario 5: the language under the language](05-language-under-the-language.md) - An agent language takes hold as an intermediate representation humans never see.
* [Scenario 6: no language at all](06-no-language.md) - The programming language disappears: non-text output, or the model runs the task itself.
